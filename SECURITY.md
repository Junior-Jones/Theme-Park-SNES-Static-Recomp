# Security policy

The current 1.0.0 release is supported. Download releases only from this
repository's Releases page. No game ROM is included.

Please report vulnerabilities privately through GitHub's Security tab using
Report a vulnerability. Do not publish exploit details, credentials, game ROMs,
or personal settings in public issues. Gameplay bugs are not security reports;
please send those to Junior Jones at https://x.com/JJ_Retro.

Build workflows use read-only repository permissions and a commit-pinned
checkout action. SDL3 downloads are pinned by version and SHA-256.
