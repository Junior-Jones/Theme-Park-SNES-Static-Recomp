This is the non-widescreen release source. Historical development receipts are not current release acceptance claims. Native hardware owners, generated static authority and source-generation material are retained; ROM-free launcher and renderer regression tests are included; gameplay probes and scripted ROM routes are excluded. Error handling and ordinary user diagnostics remain production features.


RecompLauncher uses the included `recomplauncher.json` for ROM setup, direct Play, full-screen settings, save backups and diagnostic logs. For direct launching, use `Launcher.exe --game "path/to/Theme Park.sfc"`; bare `--game` uses the saved ROM path. Options can be combined with `--fullscreen` or `--windowed`. Widescreen remains excluded.
