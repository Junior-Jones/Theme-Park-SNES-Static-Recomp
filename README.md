# Theme Park (SNES) — 1.0.0

[Download the Windows x64 release](https://github.com/Junior-Jones/Theme-Park-SNES-Static-Recomp/releases/latest).
Extract the ZIP and run Launcher.exe. Supply your own supported PAL ROM; no ROM is included.

[![Windows CI](https://github.com/Junior-Jones/Theme-Park-SNES-Static-Recomp/actions/workflows/windows-ci.yml/badge.svg)](https://github.com/Junior-Jones/Theme-Park-SNES-Static-Recomp/actions/workflows/windows-ci.yml)

See [README.txt](README.txt) for ROM requirements, controls, build instructions and known limitations, and [VERSION.txt](VERSION.txt) for release features.

This is the non-widescreen release source. Historical development receipts are not current release acceptance claims. Native hardware owners, generated static authority and source-generation material are retained; development tests, probes and scripted gameplay are excluded. Error handling and ordinary user diagnostics remain production features.
