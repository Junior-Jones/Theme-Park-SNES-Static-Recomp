# Milestone Zero — project freeze

Project: Theme Park SNES static recompilation. Workflow authority: Starter SNES v10.

Target identity is bound to canonical/original SHA-256 `c0a7e27131a7d8c9ef52a5227329e6de5846c045a9da1f3f84845e3be8e4efba`, 1,048,576 bytes, no copier header. Detailed header, vectors, mapping evidence and uncertainties are produced by 01C.

Static context key: `PBR:PC:E:M:X`. Unknown width/context/target/epoch/device semantics fail closed. Candidate or observation is never proof. Production runtime decoding and target learning are forbidden.

Machine time will use an integer master-clock/raster basis. Exact PAL timing belongs to 09C. PPU, DMA/HDMA, input, S-SMP/S-DSP and cartridge semantics remain explicit later-owner frontiers.

Oracle use is disabled until the complete static core exists. Frontend construction begins after the 18C certificate. No executable may be created or run.

The canonical ROM remains outside the project. Builds, caches, owner media, research, oracle material, archives, tests and frontend files are excluded from release. Current production source is selected only through an explicit allow-list; the construction-time release allow-list is empty.

Frontiers: `config/frontier-ledger.csv`. Phases: `config/phase-table.csv`. Longitudinal owners: `config/longitudinal-milestone-ledger.csv`.
