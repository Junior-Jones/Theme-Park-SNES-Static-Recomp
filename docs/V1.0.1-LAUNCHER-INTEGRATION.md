# Version 1.0.1 RecompLauncher integration

Adapted from the instructions in the maintainer's Uncharted Waters support PR:
https://github.com/Junior-Jones/Uncharted-Waters-New-Horizons-SNES-Static-Recomp/pull/2

Theme Park ships its own format-1 recomplauncher.json at the repository root and
next to Launcher.exe in every Windows ZIP. CMake copies it and release documents
into the runtime output. The README links to the verified Theme Park listing:
https://recomplauncher.com/game/theme-park-snes-static-recomp

Play invokes Launcher.exe --game with the player's selected ROM path. Bare
--game uses settings.ini [ROM] Path. Paths containing spaces/Unicode use Windows'
normal quoting rules; relative explicit paths resolve against the caller's
working directory before portable initialization. --fullscreen and --windowed
combine with --game. Invalid, duplicate or conflicting options are rejected.

Direct Play uses the existing exact size/SHA-256 ROM loader and asynchronous
startup. Only a successful load bypasses first-run Welcome and starts play;
errors return to ordinary Browse/Run without an automatic retry loop. Ordinary
startup without arguments keeps its previous Welcome and Run behavior.

The manifest exposes the existing FullScreenOnPlay setting, actual Saves folder,
and Logs collection (including legacy root audio logs). New audio telemetry is
written to Logs/audio-runtime.log. Widescreen is excluded from this release and
is not advertised as a setting; unsupported --port-widescreen is rejected even
when combined with other arguments. No other game's code or ROM data is used.

Headless tests use Windows' real command-line tokenizer and cover parsing and
ROM-path selection. ROM-free actual-renderer fixtures protect all six graphics
corrections. The production Windows build, CTest, official schema validation,
source hashes, version resources and allowlisted ZIP are checked by Windows CI.
Desktop presentation and actual GUI autoplay were not exercised in these
headless checks; the startup orchestration is code reviewed.

Official schema and guidance:
https://recomplauncher.com/schema/recomplauncher.json
https://github.com/elripalda/RecompLauncher/blob/main/docs/DEVELOPERS.md
