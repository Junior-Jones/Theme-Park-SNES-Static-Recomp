# S-DSP Gaussian coefficient provenance

Theme Park's fixed 512-entry interpolation coefficient array is architectural S-DSP
hardware data. It was independently transcribed from the SnesLab
`S-DSP/Gaussian Filter` table, permanent revision `oldid=11666`, which is published
under Creative Commons Attribution 4.0:

- https://sneslab.net/mw/index.php?title=S-DSP/Gaussian_Filter&oldid=11666
- https://creativecommons.org/licenses/by/4.0/

The transcription was checked entry-for-entry against all 512 published decimal
values. Its canonical little-endian unsigned-16 coefficient SHA-256 is
`0acd5077942f6cc6676829bc1954a05aeaad51be716f62d9ef4e8e7c94685af2`.

No coefficient array, DSP implementation, target address, ROM data or result was
copied from any of the six comparison recomp projects. Their audio work was examined
only to select proof questions and workflow checks.
