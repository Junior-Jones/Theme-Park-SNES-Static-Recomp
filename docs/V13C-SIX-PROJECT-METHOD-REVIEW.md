# 13C six-project method review

This review transfers process only. No foreign ROM address, generated body, target hash, acceptance result, or game-specific semantic was copied into Theme Park.

| Project | Method retained | Boundary applied to Theme Park |
|---|---|---|
| Rock n' Roll Racing | Source-owned ARAM discovery, exact-PC dispatch, executable-byte bitmap, and unknown-PC/opcode failure | Its target PCs, opcode bodies, runtime owners, hashes, and results are excluded. Theme Park independently implements its 78 reached forms. |
| Top Gear | Direct body-per-context AOT and explicit no-silent-fallback rule | Historical trace/oracle coverage is not authority here; Theme Park discovery is reconstructed upload data only. |
| SimCity | Compact exact-PC generation, direct semantic helpers, and instruction-cycle scheduler consumption | Do not retain stacked milestone dispatchers or route-specific patches; one current Theme Park AOT owner is selected. |
| Civilization | Production-purity audit: admitted contexts, generated contexts, protected bytes, and linked sources must agree | Audit structure transfers; its audio program and evidence do not. |
| Jungle Strike | Project-owned static S-SMP, ARAM knownness, finite computed-target closure, and project-owned later S-DSP separation | No third-party runtime APU is linked. Host audio and S-DSP remain outside 13C. |
| Gundam Wing | Treat executable/control-flow bytes as epoch authority and explicitly guard mutable or computed boundaries | Theme Park has no admitted mutable instruction field in epoch 1. Its three jump tables are protected control-flow bytes and runtime code writes stop pending a new proved epoch. |

The resulting Theme Park method is: reconstruct the exact upload; discover from `$0300`; close finite table targets; understand each reached opcode, flag, address mode, stack action, port access, and cycle cost; generate exact-PC begin/complete bodies; guard instruction and control-flow bytes; then compile only that closed source set. The oracle contributes zero contexts and zero semantics.
