- 71,986 conservative source-candidate S-CPU contexts (not a measured runtime-reached total);
- 78,156 exact graph edges;
- 70,076 source-proved NMI RTI re-entry rows;

Every target classifies as canonical LoROM. There are:

- zero low-WRAM-mirror targets;
- zero bank-7E/7F execution targets;
- zero unmapped/noncanonical execution targets;
- zero admitted executable-RAM epochs;
- zero executable-RAM contexts;
- zero mutable operand fields;
- zero code-overlap writers requiring an epoch.

This is a control-authority proof, not an assertion that Theme Park never writes ordinary WRAM. Bytes copied or written to RAM do not become executable merely because they resemble instructions. The closed graph has no direct, indirect, return, interrupt or wake path that can select them as an S-CPU PC.

Unknown RAM PCs remain fail closed and require a new source-proved epoch. A changed opcode or newly proved RAM entry reopens 06C; no runtime decoder or learner is permitted.
